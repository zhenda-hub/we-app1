## 开发流程

1. 注册账号

- 微信公众平台：https://mp.weixin.qq.com
- 注册小程序账号，获取 AppID

2. 开发工具

- 下载 微信开发者工具
- 配置 AppID（manifest.json 第 53 行需要填入）

3. 本地开发

# UniApp 项目

npm install
npm run dev:mp-weixin # 开发模式，输出到 dist/dev/mp-weixin
npm run build:mp-weixin # 生产构建

4. 调试预览

- 微信开发者工具导入 dist/dev/mp-weixin 目录
- 真机预览：开发者工具 → 预览 → 扫码

## 服务器情况

无服务器（纯静态）

特点：数据写死在代码里

用户 → 微信小程序（前端代码）

适用：

- 展示类：公司介绍、产品展示、作品集
- 信息类：联系方式、营业时间、地址导航
- 工具类：简单计算器、换算工具、记账本

优点：零成本、免维护、上线快

---

需要服务器

特点：数据存储在后端数据库

用户 → 微信小程序 → API接口 → 服务器 → 数据库

适用：

- 用户系统：登录、注册、个人中心
- 数据交互：评论、点赞、收藏
- 在线交易：下单、支付、订单管理
- 动态内容：后台发布、实时更新

成本：服务器 + 域名 + HTTPS 证书 + 备案
